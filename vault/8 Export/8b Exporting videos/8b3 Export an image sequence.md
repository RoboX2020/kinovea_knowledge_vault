# Export an image sequence

To export a series of images from the video, use the ![[sequence.png]] **Export sequence** button in the playback screen. This brings up a dialog to configure the frequency at which the images are taken from the video.

![[exportsequence.png]]

If the checkbox **Export the key images** is checked, the frequency slider is ignored and only the key images are exported.
