# Exporting videos

The video and image export options can be accessed from the export toolbar in the playback screen.

![[exporttoolbar.png]]

## Notes in this chapter

- [[8b1 Export a video with annotations painted on]] — To export the current working zone as a new video use the ![[video.png]] Video export button, the menu File ‣ Export video, or the context menu Export video.
- [[8b2 Export an image]] — To export the current image use the ![[image.png]] Export image button or the Export image entry of the context menu.
- [[8b3 Export an image sequence]] — To export a series of images from the video, use the ![[sequence.png]] Export sequence button in the playback screen.
- [[8b4 Export a dual video or dual image]] — When using two playback screens, use the ![[video.png]] Export video or ![[image.png]] Export image buttons in the joint controls to create a single output c…
- [[8b5 Export a slideshow or a video with pauses]] — To export a slideshow video where only the key images are shown, use the ![[slideshow.png]] Export slideshow button.
