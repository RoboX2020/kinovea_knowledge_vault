# Export a slideshow or a video with pauses

To export a slideshow video where only the key images are shown, use the ![[slideshow.png]] **Export slideshow** button.

To export a video where the video is paused on key images but otherwise plays the action normally, use the ![[pausedvideo.png]] **Export paused** button.

Both options bring up the same dialog to configure the duration of each key image in the output video.
