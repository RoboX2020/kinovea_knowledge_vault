# Exporting spreadsheet documents

## Notes in this chapter

- [[8e1 Save annotations]] — To save annotations use CTRL + S or the menus Save or Save as….
- [[8e2 Export measurements from kinematics dialogs]] — To export measurements such as point positions, linear velocities, or angular accelerations, use the kinematics dialogs.
- [[8e3 Export data to spreadsheet]] — Another option to export data is to use the converters menus under File ‣ Export to spreadsheet.
- [[8e4 Citation examples]] — If you used Kinovea in your research we would very much appreciate it if you included it in your bibliography.
