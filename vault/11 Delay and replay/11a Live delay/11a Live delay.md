# Live delay

## Notes in this chapter

- [[11a1 Feature description]] — The live delay function lets you delay the display of the live stream.
- [[11a2 Applying delay]] — To delay the display of the camera stream use the delay slider or the delay input box.
- [[11a3 Recording modes]] — It is possible to record video while delay is active.
- [[11a4 Time origin]] — When recording with delay, the time origin of the resulting video is set to the real moment the record button was hit or triggered.
- [[11a5 Pause and browse]] — Pausing the camera using the pause button \[Pause\] freezes the delay buffer.
