# Key images

Video frames marked as key images show up in the key image panel below the viewport as well as in the annotation pane.

Key images can be used to quickly navigate to and annotate important moments of the video. They have a title, color and comments associated with them.

![[sidepanel.jpg]]

## Notes in this chapter

- [[4b1 Key image panel under the video viewport]] — The key image panel under the video viewport has small thumbnails of all the key images.
- [[4b2 Annotation pane]] — The annotation pane can be opened by clicking the Annotation pane button in the tool bar or by double clicking a key image thumbnail in the bottom panel.
- [[4b3 Changing the time of a key image]] — To change the time of a key image you can drag its thumbnail from the bottom panel and drop it to a new position in the timeline.
- [[4b4 Key image presets]] — It is possible to create key image presets to quickly add key images with a predefined title and color, using a keyboard shortcut.
