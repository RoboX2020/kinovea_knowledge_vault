# Annotation pane

The annotation pane can be opened by clicking the **Annotation pane** button in the tool bar or by double clicking a key image thumbnail in the bottom panel.

The key image tab in the annotation pane shows a card for each key image and is where you can change the title, color, and add comments to the selected key image.

![[keyimage-card.jpg]]

The toolbar at the top of the key image panel contains the following buttons:

|              |                                                                             |
|--------------|-----------------------------------------------------------------------------|
| [[3a1 Comparison||Add|]] | Adds a new key image at the current time.                                   |
| [[1a3 Navigation pane||Previous|]] | Moves to the previous key image in the list.                                |
| [[1a5 Video capture||Next|]] | Moves to the next key image in the list.                                    |
| Counter      | Number of key images.                                                       |
| [[1a7 Browser view||Show|]] | Toggle button to show all key images or only those within the working zone. |

The key image cards supports the following functions:

- Color box: Click to open a color picker to change the color of the key image.

- Title: Click to edit the title of the key image.

- Time: Time of the key image. This field is not editable.

- Comment field: Click to add comments to the key image.

- Delete: Deletes the key image.
