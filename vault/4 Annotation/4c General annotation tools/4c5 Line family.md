- ![[polyline.png]] **Curve**

- ![[polyline.png]] **Polyline**

- ![[circle.png]] **Circle**

- ![[distancehorizontal.png]] **Distance horizontal**

![[line1.png]]

The line tool and the circle tool can also be used to measure segment lengths and the radius or circumference of circles, see [[5j Measuring positions and distances|Measuring positions and distances]] for more information.

Furthermore the line tool can be used as a calibration stick. See [[5b Spatial calibration|Spatial calibration]] for more information.

The circle and rectangle tools have an option toggle to be drawn as filled shapes. The circle tool also has an option toggle to draw its center.
