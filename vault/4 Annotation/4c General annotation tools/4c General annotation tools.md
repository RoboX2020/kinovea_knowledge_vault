# General annotation tools

## Notes in this chapter

- [[4c1 Text]] — The text tool can be used to create small labels.
- [[4c2 Numbers]] — The number tool can be used to add consecutive numbers.
- [[4c3 Stickers]] — Stickers are pre-defined emoji images that can be added to the video to quickly illustrate a point without the need to create a text object or attach a comment.
- [[4c4 Pencil]] — The pencil tool is used to create free-hand drawings.
- [[4c5 Line family]] — The line tool and the circle tool can also be used to measure segment lengths and the radius or circumference of circles, see Measuring positions and distanc…
- [[4c6 Arrow family]]
- [[4c7 Marker]] — The marker tool identifies the location of an object or joint.
- [[4c8 Angle family]] — Tools in the angle family measure angles on a particular plane.
- [[4c9 Stopwatch family]] — The stopwatch is used to measure one or more time intervals, can associate a label and a tag with each time segment.
- [[4c10 Counter]] — The counter tool is used to count occurrences of an event or cycle.
- [[4c11 Grid tools]] — The grid tools are used to materialize a plane of motion or are used for calibration purposes.
- [[4c12 Spotlight tool]] — The spotlight tool is used to highlight a particular area of the image by dimming the rest.
- [[4c13 Magnifier]] — The magnifier creates a picture-in-picture effect with an enlarged version of the current image displayed within the original image.
