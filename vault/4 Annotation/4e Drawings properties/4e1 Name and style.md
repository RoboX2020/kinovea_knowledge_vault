# Name and style

To change the name and style of a drawing use the properties tab in the annotation pane. Click on the drawing to load it in the property editor.

![[style.jpg]]

> [!note]
> When the style of a drawing is changed it becomes the default style for new drawings of the same type.

You can also right click the drawing and select **Configuration…** to open the configuration dialog.

![[configuration.png]]
