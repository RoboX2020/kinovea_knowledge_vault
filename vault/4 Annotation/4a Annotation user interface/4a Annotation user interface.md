# Annotation user interface

Annotations are used to document key points, add commentary, drawings or insert reference images into the video. Certain tools can also be used to measure times, repetitions, angles or distances.

The following screenshot describes the parts of the interface used for annotating videos.

![[annotations-ui.jpg]]

- The [[4a1 Annotation toolbar|annotation toolbar]] has tools for adding drawings and key images.

- The [[4a2 List of key images|list of key images]] shows thumbnails of the key images added to the video.

- The [[4a3 Drawings|drawings]] are added on top of the video.

- The [[4a4 Annotation pane|annotation pane]] has tabs for editing key images and drawings.

Some annotation features are not immediately visible in the screenshot

- [[4a5 Other tools|Other tools]] can be found in different places of the interface.

- [[4a6 Big pointers|Big pointers]] can be used for presentation purposes.

- The [[4a7 Background layer|background layer]] sits between the video and the drawings.

Annotations can be saved and loaded using [[4g Saving and loading annotation files|annotation files]].

Certain external formats can be imported, see [[4h Importing external data|importing data]].
