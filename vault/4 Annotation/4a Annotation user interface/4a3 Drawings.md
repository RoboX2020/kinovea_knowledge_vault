# Drawings

Drawings are vector-based, they can be manipulated and resized after they have been added to the video.

They have a context menu that can be used to access tool-specific functions, copy and paste, and deletion.

For a description of the individual drawing tools see [[4c General annotation tools|General annotation tools]], [[4d Posture annotation tools|Posture annotation tools]], [[5h Measuring time|Measuring time]], [[5i Counting events and measuring cadence|Counting events and measuring cadence]], [[5k Measuring angles|Measuring angles]], [[5j Measuring positions and distances|Measuring positions and distances]].

For editing style and opacity options see [[4e Drawings properties|Drawings properties]].

The drawings can be attached to filmed objects even when the camera is moving, see [[6h Camera compensated annotations|Camera compensated annotations]].

> [!warning]
> Drawings are created in key images. Deleting the key image deletes all the drawings in it.
