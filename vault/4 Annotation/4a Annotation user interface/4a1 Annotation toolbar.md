# Annotation toolbar

![[annotation-toolbar.png]]

The left part of the toolbar has the following general function buttons:

|              |                                         |
|--------------|-----------------------------------------|
| ![[handtool.png]] | Manipulates drawings or pans the image. |
| ![[add-image-16.png]] | Adds a key image at the current time.   |
| ![[sidepanel.png]] | Toggles the annotation pane.            |

The rest of the toolbar has the drawing tools.

There are more tools than those immediately visible. Buttons with a small arrowhead in the top-left corner contain other tools that can be accessed by doing a right click or a long click (click and hold) on the button.

![[tools_notch.png]]

A flying menu opens with the extra tools available.

![[subtools.png]]

For a description of the individual drawing tools see [[4c General annotation tools|General annotation tools]], [[4d Posture annotation tools|Posture annotation tools]], [[5h Measuring time|Measuring time]], [[5i Counting events and measuring cadence|Counting events and measuring cadence]], [[5k Measuring angles|Measuring angles]], [[5j Measuring positions and distances|Measuring positions and distances]].

To stop using a particular tool and come back to the hand tool you can also use the `Escape` key.

> [!tip]
> You can use the middle mouse button to directly manipulate drawings without switching to the hand tool.
