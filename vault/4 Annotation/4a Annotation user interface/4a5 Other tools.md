# Other tools

Some tools are not part of the annotation toolbar and can be found in other places in the interface.

- Trajectory objects are created by right clicking the video viewport and menu **Track path**

- The coordinate system is available in the main menu **Tools ‣ Coordinate System**

- The camera test grid is available in the main menu **Tools ‣ Camera Test Grid**

- Inserting an image or SVG as a reference is done using the main menu **Tools ‣ Import Image**
