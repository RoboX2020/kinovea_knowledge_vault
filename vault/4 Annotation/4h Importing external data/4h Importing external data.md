# Importing external data

In addition to loading annotations created in Kinovea you may import annotations created in other software.

Two external formats are supported: OpenPose body poses and SRT subtitles.

## Notes in this chapter

- [[4h1 OpenPose]] — OpenPose is a software that detects human body poses in images.
- [[4h2 SRT SubRip Text subtitles]] — SRT is a simple subtitle file format containing a series of subtitles and the corresponding start and end timestamps.
