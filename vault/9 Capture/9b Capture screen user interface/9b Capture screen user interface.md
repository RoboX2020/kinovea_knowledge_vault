# Capture screen user interface

The capture screen is divided in the following areas:

![[capture-screen-ui3.jpg]]

At the top:

- The Infobar contains information about the connected camera and streaming performances.

- The [[9b2 Context bar|Context bar]] has drop downs of context variables to tag the captured files.

- The [[9b3 Quick status band|Quick status band]] gives a visual indication of the current status for recording.

In the middle:

- The [[9b4 Camera viewport|Camera viewport]] is where the camera image and drawings are visible.

At the bottom:

- The [[9b5 Annotation toolbar|Annotation toolbar]] contains drawing tools usable on the capture screen.

- The [[9b6 List of recently captured files|List of recently captured files]] displays thumbnails of the files recorded in the session.

- The [[9b7 Capture controls|Capture controls]] area has buttons to configure the camera, pause or restart the stream, switch between live and delayed view, arm and disarm the capture trigger, save an image, and start/stop recording.

- The [[9b8 Delay and duration|Delay and duration]] area controls the delay of the stream and the duration of recordings.

- The [[9b9 Output folder and file name|Output folder and file name]] area lets you pick the output folder and define the file naming pattern of recorded files.

## Notes in this chapter

- [[9b1 Infobar]] — The infobar contains information about the connected camera and streaming performances.
- [[9b2 Context bar]] — The context bar contains drop down lists of context variables.
- [[9b3 Quick status band]] — The quick status band is a colored band at the top of the viewport that gives a quick visual indication of the current status of the capture screen.
- [[9b4 Camera viewport]] — The camera viewport is the main area where the camera image is visible.
- [[9b5 Annotation toolbar]] — The annotation toolbar contains drawing tools usable on the capture screen.
- [[9b6 List of recently captured files]] — This area displays thumbnails of the recently captured files.
- [[9b7 Capture controls]] — Displays the camera configuration dialog to change options like the image size or frame rate.
- [[9b8 Delay and duration]] — The delay numerical field and slider let you adjust the amount of delay, in seconds, of the camera stream.
- [[9b9 Output folder and file name]] — The capture folder drop down list let you select the folder where captured images and videos will be saved.
