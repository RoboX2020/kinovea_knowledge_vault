# List of recently captured files

![[capturedfiles.png]]

This area displays thumbnails of the recently captured files.

> [!tip]
> This area can be folded down to save space by clicking the down arrow button in the right corner of the area.

Double clicking on a thumbnail opens the file in a playback screen. The close button removes the thumbnail from the list without deleting the file.

Right-clicking on a thumbnails brings a context menu with the following options:

|                                         |                                                                 |
|-----------------------------------------|-----------------------------------------------------------------|
| ![[television.png]] Open                       | Opens the video in a playback screen.                           |
| ![[folder_new.png]] Locate in Windows Explorer | Opens the Windows Explorer on the parent folder of the video.   |
| ![[rename.png]] Rename                     | Make the file name label editable and save the new file name.   |
| ![[hide.png]] Hide                       | Removes this thumbnail from the list without deleting the file. |
| ![[delete.png]] Delete                     | Sends the file to the Windows trash.                            |
