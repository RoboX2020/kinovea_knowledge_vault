# Network cameras and smartphones

## Notes in this chapter

- [[9e1 General]] — In order to add a network or IP camera in Kinovea use the Manual connection button on the camera tab of the explorer panel.
- [[9e2 Configuration]] — The values for the options depend on the particular brand of network camera and your own network configuration.
- [[9e3 Smartphones]] — Smartphones can be used as network cameras over the WiFi network by using a dedicated application, provided it supports streaming in MJPEG.
