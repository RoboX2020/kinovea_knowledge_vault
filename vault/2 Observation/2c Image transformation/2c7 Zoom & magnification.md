# Zoom & magnification

To zoom into the image use `CTRL` + **mouse wheel** or `CTRL` + `Minus` and `CTRL` + `Plus`.

`CTRL` + `Numpad0` resets the zoom level.

The magnifier tool can also be used to create a picture in picture magnified area.
