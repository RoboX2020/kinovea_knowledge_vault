# Image transformation

The following image transformations can be applied:

- [[2c1 Aspect ratio|Aspect ratio]]

- [[2c2 Rotation|Rotation]]

- [[2c3 Mirroring|Mirroring]]

- [[2c4 Deinterlacing|Deinterlacing]]

- [[2c5 Demosaicing|Demosaicing]]

- [[2c6 Stabilization|Stabilization]]

- [[2c7 Zoom & magnification|Zoom & magnification]]

## Notes in this chapter

- [[2c1 Aspect ratio]] — To change the aspect ratio of the image use the menus under Image ‣ Image format.
- [[2c2 Rotation]] — To change the orientation of the image use the menus under Image ‣ Image rotation.
- [[2c3 Mirroring]] — To flip the image horizontally use the menu Image ‣ Mirror.
- [[2c4 Deinterlacing]] — To deinterlace the video use the menu Image ‣ Deinterlace.
- [[2c5 Demosaicing]] — Videos saved in Bayer mode contain the raw sensor data before color reconstruction.
- [[2c6 Stabilization]] — To stabilize the image by a previously tracked object, use the menu Image ‣ Stabilization and select a track.
- [[2c7 Zoom & magnification]] — To zoom into the image use CTRL + mouse wheel or CTRL + Minus and CTRL + Plus.
