# Introduction

Kinograms show multiple frames of the video at the same time.

The two main use-cases for kinograms are 1. the full decomposition of the motion, typically using a large grid and regular intervals, and 2. the creation of reports highlighting the posture at standard key moments of the motion, using fewer images at non regular intervals.

To enter the Kinogram mode, use the menu **Video ‣ Kinogram**.

> [!tip]
> The Kinogram mode is only enabled when the entire working zone is cached in memory. To change the amount of memory used for the cache go to **Options ‣ Preferences ‣ Playback ‣ Memory**

To exit the Kinogram mode right click in the image background and use the menu **Exit Kinogram**. Alternatevely, use the exit button at the top right of the playback screen or select another video mode.
