## Notes in this chapter

- [[2b1 Video viewport]] — The image viewport is the main area where the video is played back.
- [[2b2 Infobar]] — The infobar contains the name of the file, the image size and the frame rate.
- [[2b3 Annotation toolbar]] — The annotation toolbar contains buttons to create new key images, select the active tool and open the color profile.
- [[2b4 Working zone area]] — The working zone defines the segment of the video that the player is working with.
- [[2b5 Timeline area]] — The timeline area displays the current position within the video, time markers and the speed control.
