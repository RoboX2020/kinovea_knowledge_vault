# Keyboard navigation

The following keyboard shortcuts are defined by default:

|                          |                                               |
|--------------------------|-----------------------------------------------|
| `←` Left arrow           | Step backward one frame                       |
| `→` Right arrow          | Step forward one frame                        |
| `↟` Page up              | Big jump backward                             |
| `↡` Page down            | Big jump forward                              |
| `SHIFT` + `↟` Page up    | Small jump backward                           |
| `SHIFT` + `↡` Page down  | Small jump forward                            |
| `⇱` Home                 | Jump to the start                             |
| `⇲` End                  | Jump to the end                               |
| `SHIFT` + `←` Left arrow | At the start, will force jump back to the end |

- The big jump is 10% of the video length

- The small jump is 1% of the video length
