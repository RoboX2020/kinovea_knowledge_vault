# Options

|             |                                                    |
|-------------|----------------------------------------------------|
| Language    | Changes the language of the user interface.        |
| Time        | Changes the preferred time representation.         |
| Workspace   | Saves or exports the current state of the screens. |
| Preferences | Opens the preference pages.                        |
