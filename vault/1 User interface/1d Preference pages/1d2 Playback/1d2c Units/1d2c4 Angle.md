# Angle

The unit for angle is used in tools measuring angles and in the **Angular kinematics** window when setting the data source option to **Angle** or **Total displacement**.

The following options are available:

| Unit    | Symbol |
|---------|--------|
| Degrees | °      |
| Radians | rad    |
