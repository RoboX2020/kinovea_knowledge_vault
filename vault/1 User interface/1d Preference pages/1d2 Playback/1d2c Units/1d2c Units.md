# Units

![[playback_units.png]]

> [!tip]
> The unit for length is defined during the calibration process.

- [[1d2c1 Time]] — This option controls the format of all time-related information displayed in the program [^1].

- [[1d2c4 Angle]] — The unit for angle is used in tools measuring angles and in the Angular kinematics window when setting the data source option to Angle or Total displacement.
- [[1d2c5 Angular velocity]] — The unit for angular velocity is used in the Angular kinematics window when setting the data source option to Angular velocity.
- [[1d2c6 Angular acceleration]] — The unit for angular acceleration is used in the Angular kinematics window when setting the data source to Angular acceleration.
- [[1d2c7 Custom length unit]] — This option defines the name and symbol for an additional length unit.
