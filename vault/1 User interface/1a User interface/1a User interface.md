## Notes in this chapter

- [[1a1 Main menu]] — The main menu is described in detail on the Main menu page.
- [[1a2 Main toolbar]] — The main toolbar provides quick access to screen organization.
- [[1a3 Navigation pane]] — The navigation pane is on the left hand side of the main Kinovea window.
- [[1a4 Video player]] — When opening a video file, Kinovea functions as a video player with annotation capabilities.
- [[1a5 Video capture]] — When connecting to a camera or video capture device, Kinovea functions as a video capture tool.
- [[1a6 Dual mode]] — It is also possible to have two playback screens, two capture screens, or one of each side by side.
- [[1a7 Browser view]] — When using Kinovea without any video opened or camera connected, it functions as a file browser.
