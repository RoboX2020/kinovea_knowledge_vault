# Browser view

The browser view is displayed when there are no playback or capture screens loaded. It shows thumbnails corresponding to the active tab of the explorer panel.

![[thumbnails.png]]

In the case of the file explorer and shortcut tabs, it displays thumbnails of the files in the selected folder. In the case of the camera explorer it displays thumbnails of all the cameras connected to the computer.

## Notes in this chapter

- [[1c1 Size buttons]] — The size buttons change the size of the thumbnails.
- [[1c2 Navigation pane buttons]] — These buttons change the active tab in the navigation pane.
- [[1c3 Content preview]] — Thumbnails of video files contain multiple frames of the video.
- [[1c4 Properties overlay]] — Some metadata can be overlaid on the thumbnails of videos or images.
