# Glossary

A list of important concepts used in Kinovea and in this documentation.

## Notes in this chapter

- [[1e1 Annotations]] — Annotations in Kinovea combine all the pieces of information you add to the video.
- [[1e2 Calibration]] — Calibration is required to make measurements in real world units such as meters or seconds.
- [[1e3 Camera motion estimation, Camera tracking]] — Camera motion estimation calculates the rotation and zoom of the camera between frames.
- [[1e4 Capture folders]]
- [[1e5 Context, Context variables]]
- [[1e6 Delay, Delay buffer]]
- [[1e7 Demosaicing, Demosaicking, Debayering]]
- [[1e8 Drawing, Drawing tools]] — Kinovea drawings are vector based and their points can be moved after they are created.
- [[1e9 Frame rate]] — Kinovea deals with multiple frame rates:
- [[1e10 Intra-only, Intra-frame, All-i, All-Intra]] — Intra-only is an encoding strategy for video files where each frame is encoded independently from the others.
- [[1e11 Key frame, Key image]]
- [[1e12 Kinematics]] — Quantities such as position, velocity or acceleration.
- [[1e13 Kinetics, Dynamics]] — Quantities such as force, torque, momentum or energy.
- [[1e14 Kinogram]] — A composite image combining multiple frames from the video sequence.
- [[1e15 KVA]] — KVA is the main file format used by Kinovea to save annotations.
- [[1e16 Long-GOP]] — Long-GOP is an encoding strategy for video files where most frames depend on other frames to be decoded.
- [[1e17 Markerless tracking, Human pose estimation]] — When the subject does not wear any markers tracking often fails to follow the joint positions accurately.
- [[1e18 Plane of motion]] — Kinovea is a 2D program and all measurements are done on a single plane.
- [[1e19 Screen, Player screen, Capture screen]] — The primary user interface elements where videos and camera streams are displayed.
- [[1e20 Stabilization, Image stabilization]] — 2D image stabilization based on a previously tracked point, to remove camera shake.
- [[1e21 Stream format, Pixel format]] — The stream format describes the content of the video frames as delivered by the camera.
- [[1e22 Synchronization]] — When two videos are loaded side by side in the same Kinovea window they can be synchronized by aligning their time origin.
- [[1e23 Template matching]] — The main algorithm used in object tracking.
- [[1e24 Time origin]] — This is the “zero” time reference for time-based measurements.
- [[1e25 Tracking, Object tracking]] — Also known as “digitisation”.
- [[1e26 Window]] — A window is an instance of Kinovea that can be opened and closed independently.
- [[1e27 Working zone]] — A segment of the video defined by an in-point and an out-point.
- [[1e28 Workspace]] — A workspace in Kinovea is a collection of related windows that can be started together.
