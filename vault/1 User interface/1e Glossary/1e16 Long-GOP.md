# Long-GOP

Long-GOP is an encoding strategy for video files where most frames depend on other frames to be decoded. This is good for compression but makes it more difficult to navigate frame by frame. See [[1e10 Intra-only, Intra-frame, All-i, All-Intra|Intra-only]].
