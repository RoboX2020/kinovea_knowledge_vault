# Introduction

To measure linear or angular speed and other kinematics quantities follow these steps:

- Establish a [[5b Spatial calibration|line or plane calibration]].

- Optionally compensate for [[5c Lens distortion calibration|lens distortion]].

- For high speed videos make sure [[5d Time calibration|time is calibrated]] correctly as well.

- [[6b Trajectory object|Track a point trajectory]] or [[6d Trackable drawings|track an object]] containing an angle.

- The measured data can be displayed in two ways:

  - As a small label on the object in the viewport.

  - In a dedicated kinematics diagram.

- To export the data, use the export options in the kinematics diagrams.
