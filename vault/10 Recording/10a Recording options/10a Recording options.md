# Recording options

## Notes in this chapter

- [[10a1 Starting and stopping recording]] — Recording can be started manually by using the record button \[Record\] in the capture controls, or automatically by configuring an audio trigger.
- [[10a2 Replaying the captured video]] — The videos recorded during the session are added to the list of recently captured files.
- [[10a3 Output options]] — The path to save the recording and the file name of the output video are based on the options under Options ‣ Preferences ‣ Capture ‣ Video naming.
- [[10a4 Performances]] — When the recording process is not fast enough to sustain the camera framerate, images are skipped (dropped) and not added to the output video.
- [[10a5 Automation scenario]] — It is possible to setup Kinovea to record and replay videos multiple times in a row without manual interaction.
