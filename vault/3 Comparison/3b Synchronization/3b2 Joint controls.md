# Joint controls

![[joint-controls.png]]

The playback controls are the same as for individual playback screens but act on both videos at the same time.

The other buttons have the following functions:

- ![[jointorigin.png]] Set the time origin in both videos to their respective current time.

- ![[syncmerge.png]] Enable or disable superposition of the videos into one another.

- ![[swap.png]] Swap the playback screens.
