# Command editor

To enable post-recording commands right click the background of a capture screen and choose the menu **Post-recording command…**. Check the **Enable post-recording command** checkbox and enter the command line to execute.

You can call multiple programs, add each command on its own line. The commands are executed sequentially and the whole thing runs in a background thread.

Lines starting with `#` are treated as comments and ignored.
