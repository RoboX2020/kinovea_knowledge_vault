# Window name

By default windows are assigned random Ids to identify them internally.

You can assign a custom name to each window by using the menu **Window ‣ Window properties…**.

![[window-props.png]]

The name of the Window can be seen in the window title bar in square brackets.

![[window-title.png]]

> [!warning]
> Do not use the same name for different windows. Even though windows have internal unique Ids, the name is used in certain functions like identifying windows in the command line options or for interprocess communication.
