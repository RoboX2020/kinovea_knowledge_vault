# Deleting old windows

To delete old windows use the menu **Window ‣ Window manager…**, select the window to delete from the list, and click the **Delete** button.

![[window-delete.png]]

> [!tip]
> Window state is stored in XML files in the application data folder under the Windows subfolder. You can manually delete old window files from this folder if needed.
