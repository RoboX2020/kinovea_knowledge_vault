# Reopening previous windows

When Kinovea is started it will reopen the last window that was open when it was last closed.

To reopen another window use the menu **Window ‣ Reopen window** and select the desired window from the list. Alternatively use the Window manager, **Window ‣ Window manager…**, and select from the list.

![[window-reopen2.png]]

The icon next to the window name or id indicates the type of content it is hosting.
