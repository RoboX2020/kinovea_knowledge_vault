# Workspaces

A workspace is a predefined set of windows that are meant to be opened together. Each window in the workspace has its own content and state.

Workspaces are built on top of the [[12a Multi-window system|Multi-window system]].

To create and delete workspaces, use the menu **Window ‣ Manage workspaces…**.
