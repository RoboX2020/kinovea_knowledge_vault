# Lens distortion calibration

Revamped:

<https://www.kinovea.org/en/forum/viewtopic.php?id=1977>

## Notes in this chapter

- [[5c1 Introduction]] — When using cameras with significant distortion is it important to calibrate it in Kinovea before making measurements.
- [[5c2 Distortion coefficients]] — The description of the lens distortion is done in the lens calibration dialog in the menu Tools ‣ Camera calibration.
- [[5c3 Visual estimation]] — In this approach the distortion is estimated visually by directly changing the distortion coefficients and trying to align the grid on the image.
- [[5c4 Distortion grid]] — In this approach the distortion is estimated programmatically by Kinovea from a set of distortion grid objects manually placed over images of the video.
- [[5c5 Agisoft Lens]] — Agisoft Lens is an automatic lens calibration software.
- [[5c6 Exporting and importing distortion parameters]] — The distortion parameters are saved in the KVA file but if you want to re-use the same parameters on a different video you can export them to a separate file.
