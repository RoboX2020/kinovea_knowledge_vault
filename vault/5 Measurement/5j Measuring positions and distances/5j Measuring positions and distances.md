# Measuring positions and distances

## Notes in this chapter

- [[5j1 Introduction]] — To measure positions and distances on video images, it is necessary to first perform calibration.
- [[5j2 Points]] — The marker tool can be used to measure the position of a point in the current coordinate system or its distance to the origin.
- [[5j3 Lines]] — The line tool can be used to measure the distance between two points.
- [[5j4 Circles]] — The circle tool has display options to show the center position, radius, diameter, and circumference of the circle.
