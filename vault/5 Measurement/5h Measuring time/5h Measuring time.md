# Measuring time

## Notes in this chapter

- [[5h1 Time position]] — The current time position is visible under the main timeline.
- [[5h2 Time unit]] — The time unit can be changed from the menu Options ‣ Time or from Options ‣ Preferences ‣ Playback ‣ Units ‣ Time.
- [[5h3 Time origin]] — Times displayed are relative to the time origin defined for the video.
- [[5h4 Relative clock]] — To annotate the video with the current video time use the clock tool ![[clock-frame.png]].
- [[5h5 Time intervals]] — To measure a time interval use the Stopwatch tool ![[stopwatch.png]].
- [[5h6 Time scale]] — Videos filmed with high speed cameras or in high speed mode can have a video frame rate different from the capture frame rate.
